How to read this

Four things worth knowing before you start

Bottom line: Each chapter is one HTML file that saves its own progress. Nothing is installed, and no chapter depends on this index page.

1

Tick steps as you finish them

Click the circle or the step title to mark a step done. Progress is written to browser storage on the chapter's own page, so keep the files in one folder and open them from there. The Reset button in a chapter's top bar clears that chapter only.

2

Every procedure ends with an Expected line

An Expected: line describes what you should see when the step worked. If what you see does not match, stop there rather than continuing, because later steps assume the earlier result.

3

Callouts mean specific things

Key point is the reason something works. Warning is a mistake that costs you time. Note is context you can skip on a first pass. Anything marked [Unverified] could not be confirmed against the official Godot documentation.

4

The version is fixed at Godot 4.7.1-stable

Every chapter is written and checked against the Standard build of Godot 4.7.1-stable using GDScript, not the .NET build. Earlier 4.x versions differ in the physics engine default and in some import settings.

Reference

Conventions used in every chapter

Bottom line: Names, folders and layer numbers are identical across the series. If a chapter names a node, it means the node in the tree below.

Folder layout

Godot's Attach Script dialog defaults to the scene's folder. Change it to res://script/ every time.

res://scene/          player.tscn, building.tscn, level.tscn
res://script/         player.gd, building.gd, hud.gd
res://asset/model/    imported .glb files
res://asset/audio/    sound files
res://asset/material/ saved .tres materials
Player scene tree 
Player (CharacterBody3D)      ← player.gd attached here
├── CollisionShape3D          CapsuleShape3D, radius 1.5, height 8, position y 4
├── Facing (Node3D)           the ONLY node that rotates; must stay at 0,0,0
│   ├── Body (MeshInstance3D)
│   ├── WallRay (RayCast3D)
│   └── Fist (Area3D)         monitoring stays ON
└── CameraPivot (Node3D)      never rotates with the character
    └── SpringArm3D
        └── Camera3D
Collision layers

collision_layer is a bitmask, so the value for a layer is 2 raised to the power of the layer number minus one. Layer 4 is the value 8, not 4.

LayerNameBitmask value
1World1
2Player2
3Buildings4
4Rubble8
5HitDetection16
GDScript style in every code sample
  • Explicit self. on member access, and never on locals, parameters, globals, node paths or enum constants.
  • Explicit type hints everywhere: var speed: float = 8.0, never :=.
  • Typed @onready node references instead of repeated $Path lookups.
  • A return type on every function, usually -> void.
  • Four-space indentation. Godot's own default is tabs; either works if you keep it consistent.
  • Tuning numbers are exported so you can change them in the Inspector.
